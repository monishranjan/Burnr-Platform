# Burnrs

Burnrs is a privacy-first platform providing fast, secure, and disposable temporary email addresses. Our goal is to help users protect their personal inboxes from spam, promotional clutter, and data tracking by providing instant, anonymous email addresses on the fly.

## 🚀 Features

- **Instant Temporary Inbox**: Generate a disposable email address instantly with a single click.
- **Privacy Focused**: No registration, personal information, or passwords required. 
- **Auto-Deletion**: For your security and peace of mind, all messages and inboxes are automatically deleted after 24 hours.
- **Modern User Experience**: Built with a sleek, responsive glassmorphic UI that works perfectly on both desktop and mobile devices.
- **Copy & Go**: Easily copy your generated email to the clipboard and use it wherever needed.

## 💻 Tech Stack

- **Frontend**: Built with [Next.js (App Router)](https://nextjs.org/) and [React](https://react.dev/), styled using [Tailwind CSS](https://tailwindcss.com/) and Lucide Icons.
- **Backend**: Powered by a robust Node.js backend.
- **Deployment**: Hosted and continuously deployed on [Vercel](https://vercel.com/).

## 🛠 Getting Started (Local Development)

If you wish to run Burnrs locally on your machine, follow these steps:

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Setup the Backend (Server)
\`\`\`bash
cd server
npm install
# Start the backend server
node server.js
\`\`\`

### 2. Setup the Frontend (Client)
In a new terminal window:
\`\`\`bash
cd client
npm install
# Start the Next.js development server
npm run dev
\`\`\`

### 3. View the App
Open your browser and navigate to \`http://localhost:3000\` to see the application running.
