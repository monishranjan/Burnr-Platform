# Burnrs - Temporary Email Generator

Burnrs is a privacy-first platform that provides free, disposable email addresses to help users stay anonymous and secure online. 

In a world full of spam, promotional emails, and data tracking, Burnrs offers a hassle-free way to protect your real identity. Generate a temporary email address instantly, use it to sign up for services, and let it automatically self-destruct.

## Features

- **Instant Access:** Generate a temporary email address with a single click. No registration or personal information required.
- **Privacy First:** We do not track your personal identity. All messages and inboxes are strictly temporary.
- **Auto-Deletion:** To maintain security and cleanliness, all emails are automatically discarded after 24 hours.
- **Modern UI:** Built with a sleek, responsive, and glassmorphic design for the best user experience across desktop and mobile devices.

## Tech Stack

This project is built using modern web technologies:
- **Frontend:** Next.js (App Router), React, TypeScript
- **Styling:** Tailwind CSS, Lucide Icons
- **Deployment:** Vercel

## Getting Started

To run the Burnrs client locally on your machine:

1. **Clone the repository**
2. **Navigate to the client directory:**
   ```bash
   cd client
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run the development server:**
   ```bash
   npm run dev
   ```
5. **Open your browser** and visit `http://localhost:3000` to view the application.
